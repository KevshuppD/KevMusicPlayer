Primera versión de **KevMusic Desktop**, el control remoto de KevMusicPlayer para el PC (Linux).

- **Emparejamiento** con el teléfono por la red Wi-Fi con un código de 6 cifras; se reconecta solo
- **Inicio** con escuchado recientemente, lo que más escuchas, agregado recientemente y tus artistas
- **Reproduciendo** con carátula grande y letra sincronizada (toca una línea para saltar ahí) con traducción
- **Biblioteca**: canciones con búsqueda y orden, artistas, álbumes y listas
- **Cola**: saltar, quitar y poner a continuación
- **Descargar** con el bot de Telegram del teléfono: busca canciones, álbumes y artistas; lo descargado queda en el teléfono como siempre
- **Teclas multimedia** del teclado y applet de sonido de Cinnamon/GNOME (MPRIS)
- **Actualizaciones** automáticas desde GitHub
